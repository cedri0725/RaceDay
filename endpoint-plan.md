# RaceDay API Endpoint Plan

## Endpoint Specification Table

| HTTP Method | Route | Description | Role Required | Request Body | Expected Response |
|-------------|-------|-------------|---------------|--------------|-------------------|
| POST | /api/auth/register | Register a new user account (Participant or Organiser) | None (Public) | { "email": "string", "password": "string", "fullName": "string", "phoneNumber": "string", "role": "string" } | 201 Created - { "user_ID": 1, "email": "string", "full_Name": "string", "role": "string", "token": "JWT_token" } 400 Bad Request - { "errors": ["validation messages"] } |
| POST | /api/auth/login | Authenticate user and return JWT token for session management | None (Public) | { "email": "string", "password": "string" } | 200 OK - { "token": "JWT_token", "user": { "user_ID": 1, "email": "string", "full_Name": "string", "role": "string" } } 401 Unauthorized - { "message": "Invalid email or password" } |
| GET | /api/users/profile | Retrieve the currently logged-in user's profile information | Any (Logged In) | None | 200 OK - { "user_ID": 1, "email": "string", "full_Name": "string", "phone_Number": "string", "role": "string", "created_At": "datetime" } 401 Unauthorized - { "message": "User not authenticated" } |
| PUT | /api/users/profile | Update the current user's profile information | Any (Logged In) | { "full_Name": "string", "phone_Number": "string" } | 200 OK - { "user_ID": 1, "email": "string", "full_Name": "string", "phone_Number": "string" } 400 Bad Request - { "errors": ["validation messages"] } 401 Unauthorized - { "message": "User not authenticated" } |
| GET | /api/events | Retrieve all events with optional filters (by date, location, or status) | Any | None | 200 OK - { "events": [ { "event_ID": 1, "event_Name": "string", "description": "string", "event_Date": "datetime", "location": "string", "max_Capacity": 0, "is_Active": true, "organiser_Name": "string" } ] } |
| GET | /api/events/{id} | Retrieve detailed information for a specific event by ID | Any | None | 200 OK - { "event_ID": 1, "event_Name": "string", "description": "string", "event_Date": "datetime", "location": "string", "max_Capacity": 0, "is_Active": true, "organiser": { "user_ID": 1, "full_Name": "string" }, "categories": [ { "category_ID": 1, "category_Name": "string", "entry_Fee": 0.00, "start_Time": "time" } ] } 404 Not Found - { "message": "Event not found" } |
| POST | /api/events | Create a new event in the system | Organiser | { "event_Name": "string", "description": "string", "event_Date": "datetime", "location": "string", "max_Capacity": 0 } | 201 Created - { "event_ID": 1, "event_Name": "string", "description": "string", "event_Date": "datetime", "location": "string", "max_Capacity": 0, "is_Active": true, "created_At": "datetime" } 400 Bad Request - { "errors": ["validation messages"] } 401 Unauthorized - { "message": "User not authenticated" } 403 Forbidden - { "message": "User is not an organiser" } |
| PUT | /api/events/{id} | Update an existing event's details | Organiser | { "event_Name": "string", "description": "string", "event_Date": "datetime", "location": "string", "max_Capacity": 0 } | 200 OK - { "event_ID": 1, "event_Name": "string", "description": "string", "event_Date": "datetime", "location": "string", "max_Capacity": 0 } 400 Bad Request - { "errors": ["validation messages"] } 404 Not Found - { "message": "Event not found" } 403 Forbidden - { "message": "You do not own this event" } |
| DELETE | /api/events/{id} | Soft delete an event by setting Is_Active to false (does not permanently remove) | Organiser | None | 200 OK - { "message": "Event deactivated successfully" } 404 Not Found - { "message": "Event not found" } 403 Forbidden - { "message": "You do not own this event" } |
| GET | /api/categories | Retrieve all available event categories | Any | None | 200 OK - { "categories": [ { "category_ID": 1, "category_Name": "string", "description": "string", "distance_Km": 0.00 } ] } |
| POST | /api/categories | Create a new event category (e.g., 5km, 10km, Half Marathon) | Organiser | { "category_Name": "string", "description": "string", "distance_Km": 0.00 } | 201 Created - { "category_ID": 1, "category_Name": "string", "description": "string", "distance_Km": 0.00 } 400 Bad Request - { "errors": ["validation messages"] } 409 Conflict - { "message": "Category already exists" } |
| GET | /api/events/{eventId}/categories | Retrieve all categories associated with a specific event, including entry fees and start times | Any | None | 200 OK - { "event_ID": 1, "event_Name": "string", "categories": [ { "event_Category_ID": 1, "category_ID": 1, "category_Name": "string", "entry_Fee": 0.00, "start_Time": "time" } ] } 404 Not Found - { "message": "Event not found" } |
| POST | /api/events/{eventId}/categories | Add an existing category to a specific event with entry fee and start time | Organiser | { "category_ID": 1, "entry_Fee": 0.00, "start_Time": "time" } | 201 Created - { "event_Category_ID": 1, "event_ID": 1, "category_ID": 1, "entry_Fee": 0.00, "start_Time": "time", "is_Active": true } 400 Bad Request - { "errors": ["validation messages"] } 404 Not Found - { "message": "Event or Category not found" } 409 Conflict - { "message": "Category already added to this event" } |
| DELETE | /api/events/{eventId}/categories/{categoryId} | Remove a category from an event (does not delete the category itself) | Organiser | None | 200 OK - { "message": "Category removed from event successfully" } 404 Not Found - { "message": "Event-Category relationship not found" } 403 Forbidden - { "message": "You do not own this event" } |
| POST | /api/enrolments | Enrol a participant in an event category (participant registers for a specific race) | Participant | { "event_Category_ID": 1 } | 201 Created - { "enrolment_ID": 1, "event_Category_ID": 1, "participant_ID": 1, "enrolment_Date": "datetime", "status": "Pending" } 400 Bad Request - { "errors": ["Already enrolled", "Event capacity full"] } 401 Unauthorized - { "message": "User not authenticated" } 404 Not Found - { "message": "Event category not found" } |
| GET | /api/enrolments/my | Retrieve all enrolments for the currently logged-in participant | Participant | None | 200 OK - { "enrolments": [ { "enrolment_ID": 1, "event_ID": 1, "event_Name": "string", "category_Name": "string", "entry_Fee": 0.00, "enrolment_Date": "datetime", "status": "Pending", "result": { "finish_Time": "time", "position": 0 } } ] } |
| GET | /api/enrolments/event/{eventId} | Retrieve all enrolments for a specific event (for organisers to see participant registrations) | Organiser | None | 200 OK - { "event_ID": 1, "event_Name": "string", "enrolments": [ { "enrolment_ID": 1, "participant_ID": 1, "participant_Name": "string", "category_Name": "string", "enrolment_Date": "datetime", "status": "Pending" } ] } 404 Not Found - { "message": "Event not found" } |
| PUT | /api/enrolments/{id}/status | Update the status of an enrolment (Approve, Reject, or Cancel) | Organiser | { "status": "string" } | 200 OK - { "enrolment_ID": 1, "status": "Approved", "updated_At": "datetime" } 400 Bad Request - { "errors": ["Invalid status value"] } 404 Not Found - { "message": "Enrolment not found" } 403 Forbidden - { "message": "You do not own this event" } |
| POST | /api/results | Record a participant's race result after the event (time, position) | Organiser | { "enrolment_ID": 1, "finish_Time": "time", "position": 0 } | 201 Created - { "result_ID": 1, "enrolment_ID": 1, "finish_Time": "time", "position": 0, "status": "Pending", "recorded_At": "datetime" } 400 Bad Request - { "errors": ["Result already recorded for this enrolment"] } 404 Not Found - { "message": "Enrolment not found" } |
| GET | /api/results/event/{eventId} | Retrieve all results for a specific event, sorted by position for rankings | Any | None | 200 OK - { "event_ID": 1, "event_Name": "string", "results": [ { "participant_Name": "string", "category_Name": "string", "finish_Time": "time", "position": 0, "status": "Verified" } ] } 404 Not Found - { "message": "Event not found" } |
| GET | /api/results/my | Retrieve the currently logged-in participant's personal race results history | Participant | None | 200 OK - { "personal_Results": [ { "event_Name": "string", "category_Name": "string", "finish_Time": "time", "position": 0, "status": "Verified" } ] } |
| PUT | /api/results/{id} | Update a race result (corrections to time or position) | Organiser | { "finish_Time": "time", "position": 0 } | 200 OK - { "result_ID": 1, "finish_Time": "time", "position": 0, "updated_At": "datetime" } 404 Not Found - { "message": "Result not found" } 403 Forbidden - { "message": "You do not own this event" } |
| DELETE | /api/results/{id} | Delete a race result (if recorded in error) | Organiser | None | 200 OK - { "message": "Result deleted successfully" } 404 Not Found - { "message": "Result not found" } 403 Forbidden - { "message": "You do not own this event" } |
| GET | /api/events/upcoming | Retrieve all upcoming events (event_Date >= current date) | Any | None | 200 OK - { "upcoming_Events": [ { "event_ID": 1, "event_Name": "string", "event_Date": "datetime", "location": "string", "available_Categories": 0 } ] } |
| GET | /api/dashboard/organiser | Retrieve organiser dashboard statistics (total events, total participants, pending enrolments) | Organiser | None | 200 OK - { "total_Events": 0, "total_Enrolments": 0, "pending_Approvals": 0, "recent_Events": [ { "event_ID": 1, "event_Name": "string", "enrolment_Count": 0 } ] } |
| GET | /api/dashboard/participant | Retrieve participant dashboard statistics (total enrolments, upcoming events, personal bests) | Participant | None | 200 OK - { "total_Enrolments": 0, "upcoming_Events": 0, "completed_Races": 0, "personal_Best": { "distance": "string", "time": "time" } } |
